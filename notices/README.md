# Avisos de terceiros

O executável `omie-mcp-readonly.exe` é publicado como um arquivo só, com o runtime do .NET e os pacotes abaixo dentro dele. Este é o aviso que as licenças desses componentes pedem para quem distribui o executável.

O código do próprio conector está sob a licença PolyForm Noncommercial 1.0.0 (arquivo `LICENSE` na raiz).

|---|---|---|---|
| Microsoft.NETCore.App (runtime win-x64) | 10.0.13 | MIT | [dotnet-MIT.txt](dotnet-MIT.txt) |
